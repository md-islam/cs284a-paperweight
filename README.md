# Paperweight

UC Berkeley CS184/284A · Fall 2026

## Designing the Motion of a Pop-Up Butterfly

**Material-Aware Simulation of V-Style Pop-Ups**

We propose an interactive paper butterfly simulation combining a geometric V-style pop-up mechanism with simplified material-dependent wing deformation. Physical prototypes will support comparisons across paper configurations. This repository currently contains the proposal website only; the simulator has not been implemented.

## Preview locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` from this directory and visit http://localhost:8000. No build or dependencies are required. Use the browser print preview with US Letter paper to inspect the print layout.
