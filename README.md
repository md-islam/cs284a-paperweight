# Paperweight: Pop-Up Butterfly

Team Paperweight · UC Berkeley CS 184/284A · Fall 2026

- [Proposal website](https://md-islam.github.io/cs284a-paperweight/)
- [Repository](https://github.com/md-islam/cs284a-paperweight)

This repository contains the proposal website for an interactive paper butterfly that unfolds as a book opens. The planned simulation uses JavaScript and Three.js, developed in VS Code, starting from a Three.js scene. The simulator has not been implemented here.
