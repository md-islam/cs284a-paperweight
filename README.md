# Paperweight: Pop-Up Butterfly

Team Paperweight · UC Berkeley CS 184/284A · Fall 2026

- [Published proposal website](https://md-islam.github.io/cs284a-final-project/)
- [GitHub repository](https://github.com/md-islam/cs284a-final-project)

This repository contains our static proposal website. We plan to build an interactive paper butterfly that unfolds and folds with a book, studying how paper mass and stiffness affect its shape and motion. The proposed simulator will use JavaScript and Three.js, developed in Visual Studio Code. It has not yet been implemented.
